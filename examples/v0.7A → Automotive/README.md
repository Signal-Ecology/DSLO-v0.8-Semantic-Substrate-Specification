
# **README.md — DSLO v0.8 Examples & Domain‑Alignment Artifacts**

## **Overview**
The **examples/** directory contains **non‑lineage**, **non‑binding**, and **public‑layer safe** artifacts that illustrate how DSLO geometry can be aligned with specific domains, industries, or applied systems.

These artifacts are included for:

- educational reference  
- domain‑alignment illustration  
- institutional triage history  
- scientific context  
- cross‑domain geometry examples  

They are **not** part of the DSLO v0.8 geometry lineage and are **not** referenced by any v0.8 geometry surfaces, layers, continuity declarations, or metadata.

All examples are **substrate‑neutral**, **invariant‑preserving**, and **public‑layer safe**, but **non‑operational** and **non‑derivative**.

---

## **Purpose of This Directory**
This directory exists to:

- demonstrate how DSLO geometry can be extended or aligned with real‑world domains  
- provide historical examples of DSLO triage artifacts  
- support scientific readers exploring DSLO’s cross‑domain applicability  
- show lawful domain‑alignment patterns without affecting v0.8 geometry  

Examples in this directory **must not** be used as lineage anchors for DSLO v0.8 or future releases.

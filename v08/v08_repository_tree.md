# DSLO v0.8 Public Repository — Master Structural Tree

## Overview

This document defines the canonical, sovereign file tree for **Deterministic Semantic Layered Orchestration (DSLO) v0.8**.

The repository is divided into two distinct execution zones:

1. **Active Graph Manifold ($W > 0$):** The 12 primary geometry surface directories, system core (`v08/`), glossary graph suite (`glossary_v0.8/`), and core specification metadata (`metadata/`). These carry active execution weight and are bound to sovereign Zenodo DOIs.
2. **Airgapped Public Sandbox ($W = 0$):** The `examples/` directory containing non-lineage, public-layer safe, domain-alignment triage archives (v0.7A through v0.7F).

## Surface Tri-Artifact Standard

Each of the 12 standalone geometry surface directories enforces the strict **Tri-Artifact Standard**:

* **`.jsonld`:** Deterministic, machine-ingestible schema definition.
* **`.md`:** Human-readable specification and mathematical proof layout.
* **`.xmp_a3b`:** Immutable metadata packet preserving DataCite DOIs, Shannon-Wiener-Minsky origin invariants, and licensing parameters.
